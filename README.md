# vehicle-parking-app
It is a multi-user app that manages different parking lots, parking spots and parked vehicles,this well developed app ensures that user can access multiple spots while an admin monitors the app.

## Frontend Used
**HTML**--> For developement of webpages
**CSS**--> Presentation of webpages
**BOOTSTRAP**--> For responsive webpages
**JAVASCRIPT**--> For dynamic look to webpages

## Backend Used
**FLASK**--> Web application framework
**JINJA2**--> Rendering templates
**FLASK_SQLALCHEMY**--> Object relation mapper

## DATABASE Used
**SQLITE**--> Reliable , easy-to-use
